# Bashir Saeed Auwal — Developer Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, colors and responsive styling
- `script.js` — mobile navigation and email contact link

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your real email address.
2. Add your real LinkedIn and GitHub links when available.
3. Review the project descriptions. They are intentionally labelled as planned or in development until you complete and publish them.
4. Add project screenshots and live links after building the projects.

## Preview locally
Open `index.html` in a web browser. You can also use the Live Server extension in Visual Studio Code.

## Publish free with GitHub Pages
1. Create a GitHub account at https://github.com/.
2. Create a new public repository named `yourusername.github.io`.
3. Upload `index.html`, `style.css` and `script.js` to the repository root.
4. Open the repository Settings → Pages and enable deployment from the `main` branch.
5. Visit `https://yourusername.github.io/`.

You can also deploy the folder using Netlify or Vercel.

## Accuracy note
This portfolio presents Bashir as an entry-level developer. It does not claim that planned projects are finished or that unverified technologies are professional-level skills.
